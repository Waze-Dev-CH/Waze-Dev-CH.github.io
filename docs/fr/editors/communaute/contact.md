# Contact

La communication entre utilisateurs et communauté se fait principalement sur les forums Waze et sur Discord. Pour signaler une information aux éditeurs de carte (fermeture, changement de voirie, etc.), écrivez à **report@waze-switzerland.ch**.

## Signaler une fermeture de route

Pour signaler une fermeture de route à l'équipe d'édition :

- **fermetures@waze-switzerland.ch** — pour les messages en français, italien ou anglais
- **sperrungen@waze-switzerland.ch** — pour les messages en allemand ou anglais

::: reminder
Ces adresses sont destinées aux fermetures planifiées et aux chantiers. Pour les incidents ponctuels, utilisez directement le signalement dans l'application Waze.
:::
