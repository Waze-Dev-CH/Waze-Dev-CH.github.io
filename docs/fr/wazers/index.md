# Wazers — conducteurs

Waze est la plus grande application communautaire de trafic et de navigation, disponible sur iOS et Android. Ce site est géré par des bénévoles de la communauté suisse — pas par Waze directement.

## Télécharger l'application

- [Android — Google Play](https://play.google.com/store/apps/details?id=com.waze)
- [iOS — App Store](https://apps.apple.com/app/id323229106)

## Vignette autoroutière suisse

::: tip Tester le routage vignette
Vous pouvez simuler un itinéraire avec la vignette activée directement sur la [Live Map Waze](https://www.waze.com/live-map/directions?rp_subscription=vignette-switzerland), sans ouvrir l'application.
:::

Les autoroutes suisses nécessitent une vignette annuelle. Waze intègre ce paramètre dans ses calculs d'itinéraire. Voir la page [Vignette autoroutière](/fr/wazers/vignette) pour la configuration et l'achat.
