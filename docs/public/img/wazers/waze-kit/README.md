# Kit graphique Waze (officiel)

Assets repris du kit communautaire Waze (dossier `Waze_Switzerland_Assets`), servis à `/img/wazers/waze-kit/`.

- `waze-bg.png` — illustration officielle (voitures Waze) : fond du hero de la landing (`WazerHome.vue`).
- `waze-swiss-square.png` — logo Waze Community Switzerland (wazer + croix suisse) : badge du hero.
- `icons/` — illustrations d'icônes Waze pour les tuiles :
  - `vignette.png` (add_passes), `stickair.png` (alternate_routes), `faq.png` (info),
    `editor.png` (mapscheme_editor), `scripter.png` (phone_settings).

Autres assets dispo dans le kit source si besoin : `Switzerland2x.png` (bannière block-by-block rouge suisse),
+ le pack d'icônes onboarding Waze.
