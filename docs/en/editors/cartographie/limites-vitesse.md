# Speed limits

This page covers how to set speed limits on segments in Switzerland.

## General principle

A segment's speed limit is set based on the official signage in force on the road. The value entered must match the limit actually posted on site.

Speed limit changes are regularly reported on the Swiss forum (for example a change reported on the Schartenstrasse in Wettingen). When a change occurs, verify the new signage before updating the segment.
