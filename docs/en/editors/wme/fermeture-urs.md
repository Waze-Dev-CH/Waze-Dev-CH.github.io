# Closing URs

::: note Level L2
Closing URs is reserved for editors of level 2 and above.
:::

A **UR (Update Request)** is a report submitted by a Waze user when they notice a problem on the map. Closing a UR incorrectly sends an automatic notification to the reporter indicating that the problem has been fixed, even if it has not. It is therefore essential to close them accurately.

## Solved

Mark a UR as **solved** only if you can:

1. Clearly identify the reported problem
2. Fix it in the WME
3. Save the change

## Not Identified

Close as **not identified** in these situations:

| Situation | Action |
|-----------|--------|
| Insufficient information | Contact the reporter to learn more |
| Discussion in progress | Wait until another editor has finished |
| No response from the reporter | Close after a reasonable delay |
| Real problem but impossible to fix in WME | Close and explain the limitation |

## Ambiguity: "Wrong driving direction"

The English term **"Wrong driving direction"** can refer to two different things:
- An incorrect direction of travel on the map
- An erroneous navigation instruction

Always ask the reporter for clarification before acting.

::: warning
Never close a UR as "Solved" without having made an actual change in the WME. The reporter receives an automatic notification: closing without fixing is misleading and undermines user trust.
:::
