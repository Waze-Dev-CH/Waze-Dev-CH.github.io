# The WME interface

The Waze Map Editor (WME) is available at [waze.com/editor](https://www.waze.com/editor). It is made up of three main areas.

## Left panel

The left panel lets you switch between three tabs:

- **Segments**: list of the selected segments and their properties
- **Places**: points of interest (POIs) in the visible area
- **Update Requests (URs)**: user reports to process

## Properties panel

When a segment or a place is selected, the left sidebar switches to the properties panel and shows its editable attributes: type, name, direction of travel, speed, restrictions, and so on. Tabs added by scripts are temporarily hidden.

## Top toolbar

| Tool | Shortcut | Usage |
|-------|-----------|-------|
| Selection | <kbd>S</kbd> or <kbd>Esc</kbd> | Select existing elements |
| Draw a segment | <kbd>I</kbd> | Draw a new segment |
| Turn restriction | <kbd>T</kbd> | Set a time-based restriction |
| Add a place | <kbd>P</kbd> | Create a point of interest |
| Undo | <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo the last action |
| Save | <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save the changes |

## Layers

The layers menu (icon in the top right) lets you turn on/off:

- **Satellite**: aerial base map to check the geometry
- **GPS tracks**: GPS traces from Waze drivers
- **Map Problems**: automatically detected problems
- **Update Requests**: user reports on the map
- **Editors**: editing areas of the other connected editors

## Zoom and navigation

- Zoom: mouse wheel or <kbd>+</kbd>/<kbd>-</kbd>
- Panning: hold right-click and drag (or trackpad)
- Center on your position: GPS icon in the top toolbar

::: note Note
Changes are only visible to Waze users after an update delay. See [Update delays](/en/editors/wme/delais-mise-a-jour).
:::
