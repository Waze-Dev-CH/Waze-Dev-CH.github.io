# Permanent hazards

::: warning Level L4+
Configuring permanent hazards is reserved for editors of level 4 and above. Lower-level editors must not create or modify these objects.
:::

**Permanent hazards** warn drivers of a lasting road-related risk (level crossings, turns with reduced visibility, accident-prone areas, etc.). Editing them in Switzerland follows specific rules, maintained by the community.

The complete guidelines have been updated and are published as a dedicated reference document, accessible through the Swiss forum topic.

::: note Update: June 2024
The rules for **level crossings** have been integrated into this section. They were previously in the Lanes guidelines (L3+).
:::

## Managed hazard types

The main types of permanent hazards supported are:

- Sharp turns.
- Unmarked speed bumps.
- Tolls located off the freeway.
- Lane merges.
- Complex intersections.

Level crossings exist in the list but remain rare in Switzerland. Speed cameras are not managed as permanent hazards, since reporting them is prohibited by law in Switzerland.

## Access in WME

The feature is available in WME to L4+ editors. If the segment concerned is locked at a higher level, an unlock will be required.

## Locking

A permanent hazard inherits the lock level of its segment. It has no lock level of its own to set separately.

## Procedure

Take a conservative approach: only create a permanent hazard when it is confirmed and lasting. If an existing object is doubtful, verify it on site or with the community before modifying or deleting it. Refer to the reference document for the detailed procedure.

::: note Reference document to consult
The supported hazard types and the detailed procedure are listed in the official document linked from the Swiss forum. This content is not reproduced here. Refer to the reference document before any editing.
:::

::: important Rule of caution
When in doubt, do not modify the map based on assumptions. Ask the question on the Swiss forum or on the community Discord server.
:::
