# Scripts and tools

Userscripts extend WME's features. They are installed via a script manager such as **Tampermonkey** (Chrome/Edge) or **Greasemonkey** (Firefox).

## WME Switzerland Helper

The main tool for editing in Switzerland.

**GitHub:** https://github.com/Waze-Dev-CH/WME-Switzerland-Helper

It adds to WME:

- **Swiss geographic layers** (cantonal boundaries, national aerial imagery)
- **Public transport data** (SBB stops with official names)
- A **street name check** based on Swiss conventions
- **Locking alerts** for segments at the Swiss standard

::: help Installation
1. Install [Tampermonkey](https://www.tampermonkey.net/) in your browser
2. Open the script's GitHub page and click on the `.user.js` file
3. Tampermonkey automatically offers to install it: confirm
4. Reload WME
:::

Development of the WME Switzerland Helper is documented in the [Scripters](/en/scripters/) section.
:::
