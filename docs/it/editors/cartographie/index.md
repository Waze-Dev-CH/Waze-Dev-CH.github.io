# Cartografia

Questa sezione raccoglie le regole di editing specifiche per la Svizzera. Completano le regole generali di Waze e prevalgono sulle guide dei paesi confinanti.

::: important Importante
Le regole di cartografia variano da paese a paese. In Svizzera si applicano sempre le regole locali: non trasporre mai una regola francese, tedesca o italiana senza verifica.
:::

## Perché regole svizzere?

La Svizzera è multilingue, utilizza la propria classificazione stradale (A, N1–N30, H1–…) e presenta particolarità legali uniche (vignetta autostradale, divieto degli avvisi autovelox).
