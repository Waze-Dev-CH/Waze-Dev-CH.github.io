# Editor della mappa (WME)

Il **Waze Map Editor (WME)** è lo strumento online che permette di modificare la mappa Waze. È accessibile a tutti gli utenti che dispongono di un account Waze su [waze.com/editor](https://www.waze.com/editor).

## Accesso e diritti di modifica

Guidando con l'applicazione Waze, accumuli **diritti di modifica temporanei** (validi 90 giorni) sulle zone percorse. Questi diritti determinano dove puoi modificare la mappa.

I diritti di modifica si estendono progressivamente in base al tuo [livello di editor](/it/editors/wme/niveaux).

## Server Waze

Waze opera su tre server distinti. La Svizzera si trova sul server **ROW**.

| Server | Copertura |
|---------|-----------|
| NA | America del Nord |
| IL | Israele |
| **ROW** | Resto del mondo, inclusa la **Svizzera** |

::: important Importante
In caso di dubbio, non modificare mai la mappa basandoti sulle regole di un paese vicino. Poni la tua domanda sul [forum locale](https://www.waze.com/discuss/c/editors/switzerland/romandie/4797).
:::

## Link permanente (Permalink)

Il WME offre una funzione di link permanente che permette di condividere una posizione precisa sulla mappa. Molto utile per chiedere aiuto sul forum o su Discord.

Per ottenerlo: posiziona la mappa sulla zona desiderata, poi clicca sul pulsante <kbd class="map-btn">🔗</kbd> (il 3° cerchio dall'alto, a destra dell'editor)
