# Risorse utili

Questa pagina raccoglie i link esterni e gli strumenti utili per modificare la mappa Waze in Svizzera. In caso di dubbio, le risorse locali (Wiki svizzero, forum, Discord) hanno sempre la priorità sull'improvvisazione.

## Wiki e Wazeopedia

Il Wiki in lingua tedesca è il riferimento per l'editing in Svizzera, poiché le traduzioni francesi possono accumulare ritardo.

- Wazeopedia Svizzera : https://www.waze.com/discuss/c/wazeopedia/switzerland-wazeopedia/5228
- Hub francofono (Informazioni in francese) : https://www.waze.com/discuss/t/informations-en-francais/377254
- Hub germanofono (Hauptseite) : https://www.waze.com/discuss/t/hauptseite/377253

::: note Lingue
L'hub francofono raccoglie le pagine tradotte per la Svizzera romanda. La Hauptseite resta la pagina principale lato DACH.
:::

## Forum e comunità

- Categoria Svizzera del forum Waze : https://www.waze.com/discuss/c/editors/switzerland/4790
- Forum Romandia : https://www.waze.com/forum/viewforum.php?f=836

::: help Dove porre una domanda

:::
