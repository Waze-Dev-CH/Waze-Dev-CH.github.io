# Kartografie

Dieser Abschnitt fasst die Bearbeitungsregeln zusammen, die spezifisch für die Schweiz gelten. Sie ergänzen die allgemeinen Waze-Regeln und haben Vorrang vor den Leitfäden der Nachbarländer.

::: important Wichtig
Die Kartografieregeln unterscheiden sich von Land zu Land. In der Schweiz gelten immer die lokalen Regeln: Übertragen Sie niemals eine französische, deutsche oder italienische Regel ohne Überprüfung.
:::

## Warum Schweizer Regeln?

Die Schweiz ist mehrsprachig, verwendet ihre eigene Strassenklassifizierung (A, N1–N30, H1–…) und weist einzigartige rechtliche Besonderheiten auf (Autobahnvignette, Verbot von Radarwarnungen).
