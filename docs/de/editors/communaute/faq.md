# FAQ: Häufig gestellte Fragen

## Waze-App

**Auf welchen Plattformen ist Waze verfügbar?**
iOS und Android.

**Wo bekomme ich Hilfe zur App?**
Über die [offiziellen Hilfeseiten von Google](https://support.google.com/waze) (auf Englisch) oder im [Schweizer Community-Forum](https://www.waze.com/discuss/c/editors/switzerland/romandie/4797).


## Karteneditor (WME)

**Wer kann die Karte bearbeiten?**
Jede Person mit einem Waze-Konto und einer gültigen E-Mail-Adresse kann auf den [Waze Map Editor](https://www.waze.com/editor) zugreifen.

**Welche Gebiete kann ich bearbeiten?**
Die Gebiete, in denen Sie in den **letzten 90 Tagen** mit Waze gefahren sind. Die Zugriffsrechte laufen ab, wenn Sie innerhalb dieser Frist nicht erneut auf der Strasse fahren.

**Wie bearbeite ich ein Segment, das auf einem höheren Level gesperrt ist?**
Sie können es nicht direkt bearbeiten. Beantragen Sie die Entsperrung über das Community-Forum. Sobald sie genehmigt ist, können Sie die Änderung vornehmen.


## Schweizer Besonderheiten (Fahrer)

Die Fragen auf der Fahrerseite (**Vignette und Autobahnen**, **deaktivierte Radare**, **Kraftstoffpreise**, **Meldung von Sperrungen**) sind in der [Fahrer-FAQ](/de/wazers/faq) zusammengefasst, um Dubletten zu vermeiden.

Nützliche Erinnerung für Editoren: Ein UR, der einen falschen **Kraftstoffpreis** meldet, muss als «technisch vom Editor nicht korrigierbar» geschlossen werden: Nur Fahrer, die sich weniger als 500 m von der Tankstelle entfernt befinden, können den Preis über die App aktualisieren.
