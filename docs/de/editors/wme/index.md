# Karteneditor (WME)

Der **Waze Map Editor (WME)** ist das Online-Werkzeug, mit dem die Waze-Karte bearbeitet werden kann. Er ist für alle Nutzer mit einem Waze-Konto unter [waze.com/editor](https://www.waze.com/editor) zugänglich.

## Zugang und Bearbeitungsrechte

Wenn Sie mit der Waze-App fahren, sammeln Sie **temporäre Bearbeitungsrechte** (90 Tage gültig) für die befahrenen Gebiete an. Diese Rechte bestimmen, wo Sie die Karte bearbeiten können.

Die Bearbeitungsrechte erweitern sich schrittweise je nach Ihrem [Editor-Level](/de/editors/wme/niveaux).

## Waze-Server

Waze betreibt drei separate Server. Die Schweiz befindet sich auf dem Server **ROW**.

| Server | Abdeckung |
|---------|-----------|
| NA | Nordamerika |
| IL | Israel |
| **ROW** | Rest der Welt, einschliesslich der **Schweiz** |

::: important Wichtig
Ändern Sie die Karte im Zweifelsfall niemals auf Grundlage der Regeln eines Nachbarlandes. Stellen Sie Ihre Frage im [lokalen Forum](https://www.waze.com/discuss/c/editors/switzerland/romandie/4797).
:::

## Permanenter Link (Permalink)

Der WME bietet eine Permalink-Funktion, mit der ein genauer Standort auf der Karte geteilt werden kann. Sehr nützlich, um im Forum oder auf Discord um Hilfe zu bitten.

So erhalten Sie ihn: Positionieren Sie die Karte auf das gewünschte Gebiet und klicken Sie dann auf die Schaltfläche <kbd class="map-btn">🔗</kbd> (der 3. Kreis von oben, rechts im Editor)
