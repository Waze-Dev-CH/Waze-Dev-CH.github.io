# Editor-Rollen

Zusätzlich zur Editor-Stufe stützt sich die Schweizer Waze-Community auf spezifische Rollen, die erweiterte Bearbeitungsrechte gewähren.

## Area Manager (AM)

Ein **Area Manager** verwaltet ein definiertes geografisches Gebiet und kann dort die Karte bearbeiten, ohne physisch auf allen Strassen gefahren zu sein, im Rahmen seiner Sperrstufe.

### Voraussetzungen für die Bewerbung

- Mindestens **500 signifikante Änderungen**
- Gute Kenntnis der Schweizer Bearbeitungsregeln
- Aktive Teilnahme im Forum (mehrere Beiträge)
- Registriert seit **mindestens einem Monat**

### Ablauf

1. WME öffnen und die Karte auf das gewünschte Gebiet positionieren
2. Einen oder mehrere Permalinks erstellen, die das gewünschte Gebiet abgrenzen
3. Einen Country Manager über das Forum mit diesen Links kontaktieren
4. Ein Country Manager meldet sich innerhalb von **24 Stunden**

::: important Wichtig
Area Manager müssen die Karte **mindestens einmal alle 90 Tage** bearbeiten. Nach Ablauf dieser Frist werden die AM-Rechte automatisch entzogen.
:::

## State Manager (SM)

Ein **State Manager** verfügt über vollständige Bearbeitungsrechte im ihm zugewiesenen Kanton, unter denselben Sperrregeln.

## RTC State Manager

Eine für die Schweiz spezifische Rolle (in diesem Land einzigartig): Verwaltung von Strassensperrungen in Echtzeit. Siehe [Strassensperrungen](/de/editors/wme/fermetures) für die Details der Verfahren.

## Country Manager (CM)

Die **Country Manager** stellen die Unterstützung auf nationaler Ebene sicher, wenden die Regeln an und beleben die Community. Sie sind es, die die AM- und SM-Status vergeben.

::: note Aktuelle Liste
Die namentliche Liste der CM, SM und AM entwickelt sich weiter. Konsultieren Sie den entsprechenden Abschnitt des Schweizer Wikis, anstatt sich auf eine feste Kopie zu verlassen.
:::
