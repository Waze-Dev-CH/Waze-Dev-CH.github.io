# Schliessen von URs

::: note Level L2
Das Schliessen von URs ist Editoren ab Level 2 vorbehalten.
:::

Ein **UR (Update Request)** ist eine Meldung, die von einem Waze-Nutzer erstellt wird, wenn er ein Problem auf der Karte feststellt. Ein UR falsch zu schliessen sendet eine automatische Benachrichtigung an den Melder, dass das Problem behoben wurde, selbst wenn dies nicht der Fall ist. Es ist daher unerlässlich, präzise zu schliessen.

## Behoben (Solved)

Markiere einen UR nur dann als **behoben**, wenn du:

1. Das gemeldete Problem klar identifizieren kannst
2. Es im WME korrigieren kannst
3. Die Änderung speichern kannst

## Nicht identifiziert (Not Identified)

Schliesse in diesen Situationen als **nicht identifiziert**:

| Situation | Aktion |
|-----------|--------|
| Unzureichende Informationen | Den Melder für weitere Informationen kontaktieren |
| Laufende Diskussion | Warten, bis ein anderer Editor fertig ist |
| Keine Antwort des Melders | Nach einer angemessenen Frist schliessen |
| Reales Problem, aber im WME nicht korrigierbar | Schliessen und die Einschränkung erläutern |

## Mehrdeutigkeit: « Wrong driving direction »

Der englische Begriff **"Wrong driving direction"** kann zwei verschiedene Dinge bezeichnen:
- Eine falsche Fahrtrichtung auf der Karte
- Eine fehlerhafte Navigationsanweisung

Bitte immer den Melder um eine Klärung, bevor du handelst.

::: failure Nie ohne Korrektur schliessen
Schliesse einen UR niemals als « Behoben », ohne eine tatsächliche Änderung im WME vorgenommen zu haben. Der Melder erhält eine automatische Benachrichtigung: ohne Korrektur zu schliessen ist irreführend und schadet dem Vertrauen der Nutzer.
:::
