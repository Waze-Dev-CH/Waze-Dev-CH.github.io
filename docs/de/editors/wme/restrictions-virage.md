# Abbiegebeschränkungen

Die Abbiegebeschränkungen (turn restrictions) geben Waze an, welche Bewegungen an einer Kreuzung erlaubt oder verboten sind. Sie haben einen direkten Einfluss auf die Routenberechnung.

## Beschränkungen anzeigen

Ein Segment auswählen, um die Abbiegepfeile an jedem Ende anzuzeigen:

- **Grüner Pfeil** = Abbiegen erlaubt
- **Roter Pfeil** = Abbiegen verboten
- **Kein Pfeil** = keine gespeicherte Beschränkung (standardmässig erlaubt)

Auf einen Pfeil klicken, um zwischen erlaubt und verboten umzuschalten.

## Grundregeln

- Immer die tatsächliche Beschilderung (Verkehrsschilder, Bodenmarkierungen) prüfen, bevor eine Beschränkung gesetzt wird
- Ein legales, aber gefährliches Abbiegen ist kein ausreichender Grund, es zu beschränken
- Einbahnstrassen führen zu automatischen Beschränkungen in der gesperrten Richtung

## Zeitliche Beschränkungen

Manche Abbiegungen sind nur zu bestimmten Zeiten oder an bestimmten Tagen verboten (z. B. Linksabbiegeverbot während der Hauptverkehrszeit). Um sie zu setzen:

1. Den betroffenen Abbiegepfeil auswählen
2. Auf das erscheinende Uhr-Symbol klicken
3. Die Tage und Zeitfenster festlegen
4. Mit <kbd>Ctrl</kbd>+<kbd>S</kbd> speichern

## Beschränkungen nach Fahrzeugtyp

Es ist möglich, ein Abbiegen nur für bestimmte Fahrzeugtypen (Lastwagen, Motorräder usw.) zu beschränken, indem man im Beschränkungsfenster auf « Typen bearbeiten » klickt.

## U-Turns (Wenden)

Wendemanöver werden als Abbiegebeschränkungen auf demselben Segment verwaltet. Ein Wenden nur dann erlauben, wenn:
- Das Manöver eine echte Sackgasse erzeugt
- Es legal und beschildert ist
