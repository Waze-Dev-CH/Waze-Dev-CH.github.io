::: note Notiz
Die Schwellenwerte sind indikative Mindestwerte. Die Stufen L4 bis L6 werden nicht allein durch die Anzahl der Edits erreicht: Die Zuweisung folgt Community-Kriterien, die unter [Wie man jede Stufe erreicht](/de/editors/wme/niveaux#wie-man-jede-stufe-erreicht) beschrieben sind. Ein in der Community besonders aktiver Editor kann für eine vorzeitige Beförderung vorgeschlagen werden: Entwicklung von Skripten, Hilfe für andere Editoren, Teilnahme an Mapraids und Veranstaltungen.
:::
